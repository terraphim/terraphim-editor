# Summary: public/css/persistence.css

## Purpose
Styles for `public/js/persistence.js` (#76, #73): the dirty dot on the floppy and toolbar Save button, screen-reader-only labels for the toolbar icons, the bottom-centre draft/error notice, and the native `<dialog>`s (unsaved changes, Markdown export with a read-only text area). Tokens only (from `tokens.css`, defined on `:root`), so the notice and dialogs look the same in plain and Write_On mode, like the shortcut reference.
