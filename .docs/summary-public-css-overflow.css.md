# Summary: public/css/overflow.css

## Purpose
Styles for the Overflow panel (#12), tokens only.

## Key points
- Fixed right-hand card between the top-right keyboard glyph and the bottom-right XYZ control (`--te-color-panel`, `--te-color-panel-border`, `--te-radius-popover`).
- Title in `--te-font-display` and `--te-color-accent`; text area in `--te-font-mono`; dim hint and placeholder (`--te-color-text-dim`).
- While open on wide screens the Write_On column is re-centred left of the panel; on narrow screens the panel spans the width.
