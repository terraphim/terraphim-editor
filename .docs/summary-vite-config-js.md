# File Summary: vite.config.js

## File Path
`vite.config.js`

## Purpose
Configures Vite to bundle the JavaScript wrapper as a consumable library with multiple module formats (ESM, UMD, IIFE). Also handles WASM file copying and asset organization.

## Key Configuration

### Plugins
- **`wasm()`**: Enables WASM module imports
- **`topLevelAwait()`**: Allows top-level await for WASM initialization

### Pre-Build File Copying
```javascript
mkdirSync('public/wasm', { recursive: true });
copyFileSync('pkg/terraphim_editor_bg.wasm', 'public/wasm/terraphim_editor_bg.wasm');
copyFileSync('pkg/terraphim_editor.js', 'public/js/terraphim_editor.js');
```
- Copies WASM artifacts from `pkg/` (generated by wasm-pack) to `public/` for Vite access
- Runs at config load time (pre-build step)

### Library Build
```javascript
build: {
  lib: {
    entry: resolve(__dirname, 'public/js/terraphim-editor.js'),
    name: 'TeraphimEditor',
    formats: ['es', 'umd', 'iife']
  }
}
```
- **Entry**: `public/js/terraphim-editor.js` (JS wrapper class)
- **Name**: Global variable name for IIFE/UMD (`window.TeraphimEditor`)
- **Formats**:
  - `es` → `.mjs` (modern ESM)
  - `umd` → `.umd.js` (Universal module)
  - `iife` → `.iife.js` (Immediately-invoked, browser global)

### Rollup Options
- **Externals**: `./config.js` treated as external (not bundled)
- **Output Asset Names**:
  - `style.css` → `css/terraphim-editor.css`
  - `*.wasm` → `wasm/[name][extname]`
  - Other assets → `[ext]/[name][extname]`

### Build Settings
- **Target**: `esnext` (modern JavaScript)
- **Sourcemap**: `true` (enables debugging)
- **Minify**: `esbuild` (fast minification)

## Role in Dual Build System
- Runs after `wasm-pack build` to bundle JS wrapper
- Complementary to Trunk (which handles development)
- Used by `build.sh` for final package assembly

## Integration Points
- Expects `pkg/` directory with WASM artifacts from wasm-pack
- Outputs to `dist/` (consumed by `build.sh`)
- Copies WASM files to appropriate locations for different module formats
