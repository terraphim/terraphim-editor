# Unicode KG-protected Trim

Reuses published Terraphim `NormalizedTermValue` (terraphim_types1.22.3 via terraphim_lab) for full-source contextual Unicode lowercase, and existing terraphim_automata2.1 CompiledMatcher. Canonical NFC comes from unicode-normalization0.1.25; existing unicode-segmentation dependency supplies original graphemes. Terraphim's term type lowercases/trims; it does not itself implement NFC or full Unicode case folding. Final and non-final Greek sigma share a matching key so context outside a matched term cannot hide it. This one-to-one equivalence does not implement full case folding or transliterate Straße to STRASSE.

Complete source graphemes map normalized matches back to original byte boundaries; interior expansion/contraction boundaries are refused. Original whitespace runs fold only in the matching copy. NUL framing preserves leading/trailing whitespace through the existing term type. Full lowercase output is checked against each source scalar's expansion, allowing Rust's contextual sigma value change; unknown transformations fail closed. Original spelling, UTF16 cut range validation and exact cut/tidy retention checks remain enforced.
